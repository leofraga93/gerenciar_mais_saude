# Gerenciar Mais Saude

Landing page inicial do projeto **Gerenciar Mais Saude**, criada para apresentar a proposta da plataforma e iniciar o desafio de desenvolvimento do sistema.

## Objetivo de carreira e estudo

Este projeto tambem e uma base pratica para **estudo de Prompt Engineering** e aplicacao de **IA no desenvolvimento de software**.

Estou utilizando a **IDE Cursor** e comandos orientados por IA para planejar, estruturar e evoluir este projeto, com foco em:

- integrar conhecimentos tecnicos e de produto;
- acelerar aprendizado em engenharia de comandos para IA;
- construir repertorio real para evolucao profissional na area.

Este repositorio sera usado como **vitrine de conhecimentos**, demonstrando minha evolucao em:

- Prompt Engineering;
- AI-assisted development;
- engenharia de software;
- front-end moderno;
- prototipacao rapida e iterativa;
- boas praticas de documentacao tecnica.

## Sobre o projeto

O Gerenciar Mais Saude conecta **clinicas** e **pacientes** em uma experiencia semelhante a um leilao virtual de servicos de saude:

- as clinicas podem divulgar seus servicos e propostas;
- os pacientes podem comparar opcoes e escolher a melhor alternativa para seu perfil;
- a plataforma traz mais clareza na tomada de decisao e ajuda na captacao de novos clientes para as clinicas.

Nesta primeira etapa, o foco e uma landing page simples e responsiva com:

- apresentacao da proposta de valor;
- beneficios para clinicas e pacientes;
- metricas de desempenho;
- depoimentos;
- botao de acesso ao sistema (atualmente desativado).

## Tecnologias

- React
- Vite
- Tailwind CSS

## Como executar localmente

```bash
npm install
npm run dev
```

Depois, abra o endereco exibido no terminal (geralmente `http://localhost:5173`).
